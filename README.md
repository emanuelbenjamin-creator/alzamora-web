# Coffee Bear Café & Bistró — web

Sitio estático (HTML + CSS + JS, sin dependencias) publicado en Vercel.

## Editar
- **Productos, precios y WhatsApp:** `app.js` (arriba del todo, sección CONFIGURACIÓN).
- **Textos:** `index.html`.
- **Colores y estilos:** `styles.css` (variables en `:root`).
- **Fotos:** carpeta `img/`.

## Probar en local
```
python -m http.server 8000
```
y abre http://localhost:8000

## Publicación
Publicado en Vercel desde `main` (raíz) en
https://coffee-bear-omega.vercel.app/

Cada push a `main` actualiza el sitio en 1–2 minutos.
